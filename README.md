# Cloud SQL Basics

A practical skill for provisioning, connecting to, and managing Google Cloud SQL relational database instances.

## Supported database engines

- MySQL
- PostgreSQL
- SQL Server

## Capabilities

- Enable the Cloud SQL Admin API and create database instances.
- Configure databases, users, and instance settings.
- Manage backups, high availability, and connectivity.
- Connect applications using the Cloud SQL Auth Proxy and supported connectors.
- Apply IAM, network, and encryption security practices.
- Provision resources with command-line tools and Infrastructure as Code.

## Included references

The repository contains `SKILL.md` and supporting guides covering core concepts, CLI usage, client libraries, MCP, IaC, and IAM/security. Read the relevant guide before implementing a production configuration.

## Usage

Use this skill when creating or operating Cloud SQL resources on Google Cloud. Confirm the project, region, engine version, sizing, availability requirements, network access, and backup policy before provisioning. Never place database passwords or service credentials in source control.
